Private by default

  • No ads and no tracking — MDVibe has no analytics at all.
  • Your files stay on your computer. Documents are never uploaded anywhere.
  • Images from the internet load only when you allow them.
  • Links in a document never start other programs.

Install in a minute

  1. Download MDVibe.
  2. Run MDVibe-Setup.exe. No administrator rights are needed.
  3. Open any .md file with MDVibe.
  4. Optionally, make MDVibe the default app for Markdown files.

Windows may show a SmartScreen notice because the current build is not code-signed yet. Choose “More info” → “Run anyway” if you downloaded MDVibe from this page.

Open .md files with MDVibe

  1. Right-click a .md file → Open with → Choose another app.
  2. Select MDVibe.
  3. Tick “Always use this app to open .md files” and press OK.

The installer never changes your default app on its own — you decide.

macOS and Linux versions are planned.
