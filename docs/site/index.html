Markdown, made calm.

A fast, clean Markdown viewer for Windows. Double-click a .md file and read it the way GitHub renders it — every document in its own window.

Download for Windows View on GitHub

Free · Windows 10 & 11 · No telemetry

Everything you need to read Markdown. Nothing you don't.

GitHub Flavored Markdown

Tables, task lists, footnotes, alerts and autolinks render like on GitHub.

Code that looks like code

Syntax highlighting, language labels, line numbers and one-click Copy.

One window per document

Open five files, get five independent windows. Nothing gets replaced.

Live reload

Keeps your place while an editor or an AI agent rewrites the file.

Outline & Recent

Jump through headings; reopen pinned and recent files. Hide the sidebar anytime.

Reading layouts

Comfortable, Compact, Wide or Book presets — plus page view, print and PDF.

Opens from Windows Explorer

MDVibe registers itself for .md and .markdown without taking over your current default. Right-click a file → Open with → MDVibe → Always use this app.

Light, dark, or system

A calm reading theme in both modes, with an Enhanced or Neutral Markdown style and adjustable fonts, sizes and widths.

Private by default

  • No telemetry, analytics, accounts or cloud — your documents never leave your PC.
  • Remote images are blocked until you allow them, so opening a file doesn't reveal your IP.
  • Scripts in documents never run, and links never launch programs.

Free, and it stays that way

MDVibe has no ads, no paywalls and no nags. If it saves you time, you can support its development.
